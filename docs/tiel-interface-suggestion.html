WinDock — Interface suggestions

Static preview of two proposed changes. Not code, not connected to the app. See docs/tiel-interface-suggestion.html in the repo.

Part A · guide the user better

1. Guided start (welcome dialog)

Instead of only picking a preset, pick a goal. The choice auto-selects a matching preset and opens the page that matters for it — so a new user is led straight to customization instead of facing all 8 settings pages at once.

How will you use WinDock?

We'll set up a dock that fits and show you where to change things.

🚀

Just a dock

Pinned apps at the bottom with magnification. Minimal.

🧩

Dock + info

Your apps plus a clock, weather and widgets.

🖥️

Many displays

A dock on every screen, each its own look.

Replaces the current single-step preset picker. Reuses the existing Help/preset system — no new UI framework.

Part B · spread out on large displays

2. Settings window, narrow vs. wide

Same window. On a large/ultrawide display the settings opens wider (display-aware default size), the nav column and live preview grow, and cards wrap into two columns instead of one long scroll. Your saved size always wins over the default.

Toggle the Themes tab live preview to see magnification in each layout.
