# WinDock documentation

WinDock is a macOS-style dock for Windows 11: a bar of app icons that grow under the mouse, with folders, the running apps, a clock, the weather, the tray icons, notifications and widgets. These guides explain how to use it, from the first start to every setting. The same guides open inside WinDock: press F1 in any settings window, or click the Help row in the App settings window.

- [Quick start](quick-start.md): start WinDock, pin an app, customize the dock, open its settings, pick a layout, undo and quit, in five minutes.
- [Settings guide](guide-settings.md): every settings window and panel, page, tab and card, what each setting does, and undo.
- [Docks and displays](guide-docks.md): several docks, moving them, names and titles, placement, auto-hide, layers, floating docks, the dashboard, folder windows, standalone widgets, layouts and looks.
- [Items and widgets](guide-items.md): adding items, customizing a dock, apps, folders, groups, running apps, the clock, the weather, calendars, the tray, notifications and widgets.
- [Troubleshooting](troubleshooting.md): a missing taskbar or dock, crashes, full-screen games, lost changes, save errors, performance, widget errors and resetting to defaults.
- [Widget developer reference](widgets.md) (for people writing their own widgets).
